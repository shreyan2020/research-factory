# Evidence-analysis lessons

The [matched retrospective replay](https://github.com/shreyan2020/research-factory/blob/main/TESTING.md) found no overall preference for factory-guided analysis over ordinary analysis across eight excerpt pairs. Both conditions were judged source-supported by a blinded assistant. This is a reason to keep the workflow lean, not an accuracy estimate.

| Trap | Transferable rule |
|---|---|
| Stronger provenance infrastructure was mistaken for stronger reasoning. | Retain infrastructure repairs while comparing substantive outcomes with a matched direct baseline. |
| Aggregation turned abstentions into unsupported decisive answers. | Audit abstention-to-answer transitions and preserve unresolved cases. |
| Pairwise relationships generated combinations the source never asserted. | Preserve complete source-bound events; annotation absence is not semantic negation. |
| Model-based classification followed by within-class clustering was described as unsupervised. | State each stage's actual supervision and align method intent before scaling. |
| Valid quotations and JSON coexisted with incorrect relationship interpretations. | Check execution, literal quotations, semantic support, and independent review separately. |
| Extraction repairs did not resolve mixed clusters. | Measure the actual downstream effect rather than assuming cleaner text guarantees coherent structure. |
| Context expansion or unnecessary vector transformations changed the result. | Version transformations and preserve valid caches when their full identity matches. |
| Score gains came from quotation validity rather than better answers. | Attribute improvements to the changed component and evaluate usefulness separately. |

For supplied packets, preserve IDs, roles, and schema. State provisional code definitions when only label names exist. Freeze a common codebook before quantitative label comparisons. Excerpt checking does not establish inspection of the full original document.
