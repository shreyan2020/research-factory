# Presentation lessons

| Failure or distinction | Apply the lesson |
|---|---|
| A file passed structural checks while a live interaction was not ready. | Verify the interaction required for the actual delivery setting; package validity alone is insufficient. |
| A presentation runtime or export finalizer failed after content production. | Run a representative slide through the complete save/export/render route early. Diagnose tools separately from content. |
| A preview and an editable local deck were treated as interchangeable. | Deliver and inspect the requested artifact; describe exactly what exists. |
| Polling instructions became stale after switching to classroom discussion. | Preserve the teaching objective, replace the interaction, and check notes as well as slide text. |
| Apparent rendering defects could originate in the renderer. | Inspect the saved object and rerender before changing otherwise correct content. |

Keep participant-facing copy concise and put facilitator detail in notes. This is a design choice to adapt to the audience, not evidence of improved learning.
