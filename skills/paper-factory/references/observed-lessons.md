# Paper-writing lessons

Use a proposition comparison when shortening: actors, population, scope, conditions, modality, direction, and evidence status. An excerpt request needs excerpt-level validation; do not require a full submission build unless the user requested one.

Other transferable lessons:

- Write the final method a reader needs to assess and reproduce the work. Keep the development chronology in the experiment record unless it changes validity or selection.
- Preserve active citation keys and identify the version actually read. Abstract access does not establish full-paper details.
- Present cases proportionately to the design while making material coverage differences explicit.
- Preserve deliberate figure retention, deletions, and edits the user reserved. Estimated page savings are not measured pagination.
- Keep completed analysis separate from prospective corpora. Successful extraction and computational replay do not establish semantic review.
- Correct the originating evidence table or generator as well as the prose so the error does not return.
- Retain raw history and distinguish technical checks, source adjudication, and acceptance readiness.

Apply these rules to current source material; do not import old corpus counts, page targets, or project decisions into a new manuscript.
